# Jetson 2026-11-16 源码备份摘录

文件来自电脑上的 2026-11-16 核验快照，逐文件与当时的 SHA-256 清单比对。目录保留 Jetson 工作区内的相对路径。

- 坐标校准和坐标绑定模块保留地面测点、保存和读取逻辑。三个 `coordinates.backup.*.json` 是历史校准备份。
